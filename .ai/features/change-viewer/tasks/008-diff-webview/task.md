# タスク

## 目標

実際の Git 差分をファイル別・CU 別に差分 Webview へ表示し、理由・警告・選択状態・大規模差分の概要表示を提供する。

## 背景

差分本文は常に 004 の Git 差分から生成し、入力 JSON のコード本文は使わない。未変更の周辺コードは初期表示せず、CU の区画ごとに変更内容と理由を近接表示する。大きな CU では初期表示を概要に切り替える必要がある。

依存関係: 001、005、007。006・009 と選択メッセージを共有する。

## 受け入れ条件

- ファイルをパスごとにまとめ、ファイル内で CU ごとに差分区画を分ける。
- Git の追加・削除・変更行を旧版・新版で表示し、削除行を赤色で示す。CU に追加と削除の両方がある場合は新旧を同時表示する。
- CU の summary を先に表示し、reason を展開可能な詳細として表示する。警告と「該当する実差分なし」を該当 CU に表示する。
- 未変更の周辺コードは初期表示せず、指定された複数 Edit と重複 CU の区画を正しく表示する。
- 選択中の CU を強調し、Tree View・Review Route からの選択と同期する。
- CU の実変更行が合計 1,000 行以上、または UTF-8 本文合計 1 MiB 以上の場合、初期状態は概要で、操作によりその CU の差分全文を展開できる。
- 未割当差分の選択では該当する実差分または変更概要だけを表示し、CU のソース移動を発生させない。
- 表示内容が入力 JSON の本文ではなく Git blob・差分結果に基づくことを保証する。

## 必要な検証

- 追加・削除・変更、離れた複数 Edit、共有行、名前変更、未割当差分、警告付き CU を fixture で確認する。
- 1,000 行ちょうど／1,001 行、1 MiB 未満／ちょうど／超過で概要表示への切り替えを確認する。
- CRLF、末尾改行なし、非 UTF-8 またはバイナリ概要を確認する。
- Webview へのメッセージ入力が未知の CU や未割当 ID を表示対象にできないことを確認する。
- `npm run check-types`、`npm run lint`、`npm test` を実行する。
- Extension Development Host で色、折りたたみ、展開、選択強調、ファイル別表示を目視確認する。

## リスク

MEDIUM

### 理由

表示データの組み立てと、大規模差分を概要表示に切り替える条件を扱うため。表示の誤りはレビュー理解を妨げるが、実リポジトリや入力を変更する処理ではない。

## 対象外

- Git 差分アルゴリズムと CU 照合。
- VS Code の通常エディタでのソース表示。
- Review Route と Tree View の階層構築。

## 未確定事項

- 差分の正確な HTML/CSS、色、概要文、展開ボタンの文言。
- Webview の CSP とメッセージ形式の詳細。
