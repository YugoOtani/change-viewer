# 実装記録

## 変更内容

- `reconcileChangeUnits` を追加し、CUの各Edit側をGitの実変更行へ照合した。
- ファイル不存在、バイナリ、範囲内の未変更行、該当差分なしをCU単位の警告として保持する。
- CU間で同じ行を共有しても、未割当差分からは一度だけ除外する。
- 行差分のない変更やバイナリ、権限変更を未割当差分の概要として返す。

## 受け入れ条件への対応

- 追加・削除・変更の両側を別々の行参照として扱う。
- 離れたEditと共有行を保持する。
- CUの範囲外の実変更行を未割当一覧へ残す。
- 「経路未割当CU」と「未割当差分」は別のデータとして保持する。
