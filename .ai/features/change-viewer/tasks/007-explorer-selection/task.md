# タスク

## 目標

Explorer の Tree View にファイル、CU、未割当差分を仕様どおりに階層表示し、選択状態を Review Route・差分 Webview・ソースナビゲーションへ伝播する。

## 背景

Tree View は差分をファイルパスごとにまとめ、その下に同じファイルの CU を並べる。名前変更は旧パス → 新パスの1ファイルとして扱い、CU に割り当てられない変更は専用一覧に分ける。未割当差分の選択では CU のソースエディタを開かない。

依存関係: 001、005。006・008・009 と選択状態の契約を共有する。

## 受け入れ条件

- ファイルをパスごとにグループ化し、同一ファイルの CU を子要素として表示する。
- 名前変更を旧パス → 新パスの1ファイルとして表示する。
- 未割当差分を CU とは別の専用一覧にまとめ、テキスト差分は実差分、行差分のない変更は概要へ遷移できる。
- CU 選択時は共通選択状態を更新し、差分 Webview の該当 CU を強調し、ソースナビゲーションへ渡す。
- 未割当差分選択時は CU のソースエディタを開かず、該当差分または概要だけを表示する。
- 空状態、警告付き CU、該当する実差分がない CU を区別して表示できる。

## 必要な検証

- 追加、削除、名前変更、同一ファイルの複数 CU、未割当テキスト、バイナリ・権限変更を含む fixture で Tree の階層と選択結果を確認する。
- CU の重複参照が二重の未割当差分を作らないことを 005 の結果との結合テストで確認する。
- 未割当差分を選んだときにソースナビゲーションイベントが発行されないことを確認する。
- Extension Development Host で展開、選択、警告表示、名前変更表示を目視確認する。

## リスク

MEDIUM

### 理由

Tree View の表示階層と複数表示先の選択同期を扱うため。選択の取り違えは差分とソースの対象を誤らせるが、Git の内容そのものは変更しないため。

## 対象外

- Git 差分や未割当集合の計算。
- Review Route Webview のレイアウト。
- 差分本文やソースコードの HTML/CSS 表示。
